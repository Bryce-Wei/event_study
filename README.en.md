# Event Study | Analyst Rating Changes and Abnormal Stock Returns

## Background

Analyst rating changes provide a concrete setting for studying how the stock market reacts to public information. Stock price performance before and after a rating change may also be affected by overall market movements, company earnings reports and other concurrent news. The study therefore needs to take into account the market benchmark, event timing and differences across the sample when observing a stock's relative performance before and after rating changes.

## Research Objectives

This project uses the market-adjusted method to compute abnormal returns (AR) and cumulative abnormal returns (CAR), measures the stock's relative returns before and after rating events, compares the return paths of the upgrade and downgrade groups, and assesses the uncertainty of the observed results through sample statistics. It also builds a reproducible pipeline from raw data and event alignment to chart output, providing a foundation for further expanding the sample and testing the predictive power of rating information.

It currently provides a real case that can be reproduced offline: **TSLA stock, the SPY benchmark, and 6 analyst rating changes in 2023–2024**. A simulated case with a fixed random seed is also kept, to make it easy to check the program and understand the charts.

> The real case is a hand-picked sample with public sources, containing 2 upgrades and 4 downgrades; it is not a complete ratings database. The charts illustrate the research process and observed results, and do not represent a validated trading strategy or a causal effect of rating changes.

## Quick Start

Run from the project root; Python 3.10 or later is recommended:

```bash
python -m pip install -r requirements-viz.txt

# Generate the returns table and rating events table from the bundled raw snapshots; no network needed
python prepare_real_example.py

# Run the real case; outputs charts, per-event results and statistical summary
python visualize.py --returns data/real/returns.csv --events data/real/events.csv --label "TSLA vs SPY" --output-dir docs/real

# Run the calculation-correctness and data-validation tests
python -m unittest discover -s tests -v
```

Figures for the real case are saved in `docs/real/figures/`, and computed results in `docs/real/tables/`. The current preview was generated by actually running the code in a Python environment; all 14 tests pass. The verification environment is pandas 2.2.2, NumPy 1.26.4, Matplotlib 3.8.4, SciPy 1.13.1.

The download API and historical adjusted values may change; to reproduce the numbers on this page, use the bundled snapshots. This command only downloads market data; the rating records still come from public sources compiled entry by entry in this project.

## Methodology

### 1. Event Window and Date Alignment

The newly added visualization pipeline uses **[-5, +5] trading days** by default, 11 trading days in total; `t = 0` is the trading day corresponding to the event. A non-trading day is mapped to the first trading day no earlier than the input date, with a shift of at most 7 calendar days.

The code takes windows by the trading-date index of the input returns table and does not infer exchange holidays on its own. When importing your own data, provide a complete sequence of trading days; missing quotes should be kept as missing values, rather than deleting the dates and stitching adjacent trading days together. For after-hours announcements, the event date needs to be aligned to the next trading day beforehand; the program does not automatically identify the announcement session.

Events whose windows are incomplete or contain missing/infinite returns are excluded and written to `excluded_events.csv`; input problems such as duplicate dates or duplicate events raise an error. In the current real case, all 6 events are retained.

### 2. Abnormal Returns and Cumulative Returns

Market-adjusted method: subtract SPY's return over the same period from TSLA's return, to measure how much more it rose, or how much less it fell, relative to the market.

**1. First, compute the daily returns**

Using adjusted closing prices, compute the daily returns of TSLA and SPY separately:

$$
R_t=\frac{\text{adjusted close on the day}}{\text{adjusted close on the previous trading day}}-1
$$

For example, if the price rises from 100 to 103, the return for that day is **3%**.

**2. Abnormal return AR: the day's return difference relative to the market**

$$
AR_t=R_{\text{TSLA},t}-R_{\text{SPY},t}
$$

If TSLA rises **3%** on the day and SPY rises **1%**:

$$
AR_t=3\%-1\%=2\%
$$

This means TSLA rose **2 percentage points** more than the benchmark that day. “Abnormal” here only means the difference relative to the benchmark; it does not imply statistical significance.

**3. Cumulative abnormal return CAR: add up the daily ARs within the window**

$$
CAR[a,b]=\sum_{t=a}^{b}AR_t
$$

The following is only a calculation example:

| Day relative to event | TSLA daily return | SPY daily return | AR for the day | CAR to date |
|---:|---:|---:|---:|---:|
| −1 | +1.0% | +0.5% | +0.5% | +0.5% |
| 0 | +3.0% | +1.0% | +2.0% | +2.5% |
| +1 | −2.0% | −0.5% | −1.5% | +1.0% |

So the CAR for this three-day window is:

$$
CAR[-1,+1]=0.5\%+2.0\%-1.5\%=\boxed{1.0\%}
$$

Your actual experiment uses **[-5,+5], 11 trading days in total**: first compute the AR for these 11 days for each rating event, then add them up to get that event's CAR. Finally, average the CARs of the two upgrade events to get the **+10.57%** seen earlier.

Note: **CAR is the sum of daily abnormal returns, not a compounded investment return; on its own, it also cannot prove that these returns were caused by the rating changes.**

### 3. Sample Statistics and Uncertainty

For each group's full-window CARs, compute the sample size, mean, standard deviation, a two-sided one-sample t-test and a 95% t confidence interval. The pointwise intervals for CAAR are computed from **the cross-sectional dispersion of the events' cumulative paths**, rather than by adding up the daily confidence intervals. The calculation is consistent with the [SciPy documentation for the one-sample t-test](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_1samp.html).

When there are fewer than 2 observations or the variance is zero, the test and interval return missing values. The t intervals here assume independent events; they are not simultaneous confidence bands, and no correction is made for overlapping windows or correlation. The real sample does not fully satisfy these conditions, so this part mainly demonstrates the statistical calculation rather than robust inference.

## Importing Your Own Data

`returns.csv` must contain `Date,ret,mkt`, with returns expressed as decimals; one row corresponds to one trading day. `events.csv` must contain `event_id,event_date,firm,event_type`, where the type is `upgrade` or `downgrade`, and event IDs must not repeat.

```bash
python visualize.py --returns data/local/returns.csv --events data/local/events.csv --label "My sample" --window 3 --output-dir outputs/my_sample
```

The command above uses a [-3,+3] trading-day window instead. The outputs include the daily event panel, per-event CARs, AAR/CAAR, group statistics, exclusion reasons, as well as 5 individual charts and 1 overview.

## Future Research Directions

Possible further extensions include a complete ratings sample, accurate announcement times, market-model and multi-factor benchmarks, handling of overlapping events, and out-of-sample testing. If news NLP or large-language-model features are incorporated, it should be tested separately whether they provide incremental explanatory or predictive power beyond the existing rating information; this version does not yet implement an AI prediction model.

## Conclusion

Among the 6 selected TSLA rating changes, with SPY as the benchmark, over a window of 5 trading days on each side of the event (including the event day, 11 trading days in total), the mean cumulative abnormal return was **+10.57%** for the 2 upgrade events and **−1.35%** for the 4 downgrade events. This result describes the directional difference in relative returns between the two groups in the current sample.

A two-sided one-sample t-test of whether each group's mean full-window CAR is zero gives p-values of **0.3211** and **0.4528** for the upgrade and downgrade groups, respectively. Even under the simplified assumption of independent samples, neither group reaches the 5% significance level; this does not prove that the rating changes had no effect. In addition, the small sample size, the overlap of some event windows, and interference from concurrent news such as earnings all limit how far the results can be interpreted.

Therefore, **the current evidence is not yet sufficient to confirm that rating changes have stable predictive power for returns, nor can the observed abnormal returns be attributed entirely to the rating changes.** Because the calculation window includes returns before the ratings were announced, the figures above also cannot be interpreted as the strategy return from buying after a rating is announced. This case completes a traceable, reproducible event-study pipeline; more reliable conclusions still require expanding the sample, handling event correlation and concurrent news, and conducting out-of-sample tests.
